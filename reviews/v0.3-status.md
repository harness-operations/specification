# v0.3 external validation status

**Status date:** September 25, 2026

Applied Harness Operations v0.3 set a target of external operator review and at least one independent reproduction.

At the v0.3 release-candidate stage, the project has **not received inspectable independent reproduction evidence** that satisfies the published evidence methodology.

The project therefore does not claim:

- independent validation of the reference model;
- community consensus;
- external endorsement;
- independent reproduction of the approved-artifact handoff example;
- independent live verification of the product capability matrix.

## v0.3 decision

Ship the evidence-backed project-maintained work without manufacturing an external-validation claim.

The external review target remains open as post-v0.3 follow-up. Future reports should use the repository template and the same version/scope/evidence rules as comparison contributions.

A real external report that identifies a model defect should take priority over expanding the taxonomy.

## Evidence available in v0.3

Project-maintained evidence includes:

- deterministic approved-artifact handoff failure tests;
- documentation-backed, version-scoped implementation mappings;
- credential-free exact-version interface smoke tests for Codex and Claude Code;
- canonical comparison-data validation and source links;
- production website browser QA.

None of those substitute for independent review.
