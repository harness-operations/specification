# Harness Operations

This repository is the canonical home of the emerging **Harness Operations Reference Model**.

**Status:** pre-0.1 / design in progress.

Harness Operations is being developed as a vendor-neutral, implementation-neutral reference model for the operational concerns that emerge when agent harnesses are run as an ongoing system.

The project is intentionally starting with a reference model rather than a new wire protocol. Existing standards and native harness capabilities should be composed where they already solve the problem.

## Reference Model 0.1

Canonical reference material lives under [`reference/`](reference/).

The five foundational v0.1 documents are being developed independently through focused Issues and Pull Requests:

- What is Harness Operations?
- Principles
- Reference Model
- Governance
- Standards Landscape

Shared scope and vocabulary are maintained in [`reference/terminology.md`](reference/terminology.md).

## Development process

Substantive design work begins in GitHub Issues and canonical reference material changes through Pull Requests.

- [Reference Model v0.1 roadmap](../../issues/9)
- [Contribution guide](CONTRIBUTING.md)
- [Proposals](proposals/)

Reference Model 0.1 is descriptive. It does not define a Harness Operations wire protocol, conformance program, registry, SDK, or certification scheme.
